# 임상시험 공고 알림 봇

[엘리드](https://www.ellead.com/board/recruitment)와
[대한피부과학연구소(KDRI)](https://www.kdri.co.kr/bbs/board.php?bo_table=participation)에
새 모집공고가 올라오면, **등록한 가족 중 한 명이라도 조건에 맞는 것만** 골라
텔레그램으로 보내줍니다. 본인과 자녀를 함께 등록하면 유아 대상 공고도 놓치지 않습니다.

10분마다 GitHub Actions가 자동으로 확인하므로 내 PC는 꺼져 있어도 됩니다.

---

## 처음 한 번만 설정하기 (약 10분)

### 1단계 — 텔레그램 봇 만들기

1. 텔레그램에서 **@BotFather** 를 검색해 대화 시작
2. `/newbot` 입력 → 봇 이름과 아이디(`_bot`으로 끝나야 함)를 정함
3. 받은 **토큰**을 복사해 둡니다 (`8123456789:AAE...` 형태)

### 2단계 — 내 채팅 ID 알아내기

**간편한 방법** — 이 폴더에서 아래를 실행하면 채팅 ID 확인부터 테스트 발송까지 한 번에 됩니다.

```
python setup.py
```

**직접 확인하는 방법**

1. 방금 만든 봇과의 대화창을 열고 아무 메시지나 하나 보냅니다 (예: `안녕`)
   — 이걸 먼저 안 하면 결과가 `{"ok":true,"result":[]}` 로 비어 있습니다.
2. 브라우저 주소창에 아래를 입력 (`<토큰>` 자리에 1단계 토큰을 넣으세요)

   ```
   https://api.telegram.org/bot<토큰>/getUpdates
   ```

   ⚠️ 토큰 **앞에 `bot` 을 붙여야 합니다.** `bot` 없이 `api.telegram.org/<토큰>/...`
   으로 넣으면 페이지가 열리지 않습니다. 가장 흔한 실수예요.

3. 결과에서 `"chat":{"id":123456789` 의 **숫자**가 채팅 ID입니다

### 3단계 — GitHub 저장소 만들기

1. GitHub에서 새 저장소를 만듭니다 — **Public(공개)로 만드세요.**
   비공개 저장소는 Actions 무료 사용량이 월 2,000분이라 10분 주기를 감당하지 못합니다.
   공개여도 아래 4단계의 Secrets는 암호화되어 다른 사람에게 보이지 않고,
   나이·성별도 Secrets에 넣으므로 저장소에는 개인정보가 남지 않습니다.
2. 이 폴더를 그 저장소에 올립니다:

   ```bash
   git remote add origin https://github.com/<내아이디>/<저장소이름>.git
   git branch -M main
   git push -u origin main
   ```

### 4단계 — 비밀값 4개 등록

저장소 → **Settings → Secrets and variables → Actions → New repository secret**
에서 아래 4개를 각각 추가합니다.

| 이름 | 값 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 1단계에서 받은 토큰 |
| `TELEGRAM_CHAT_ID` | 2단계에서 확인한 숫자 |
| `PEOPLE` | 아래 형식으로 한 줄 (예: `나:여성:38, 첫째:남성:6, 둘째:여성:18개월`) |

`PEOPLE` 은 **`이름:성별:나이`** 를 쉼표로 이어 쓴 것입니다.
돌 이전 아이는 `18개월` 처럼 개월로 적어도 됩니다.
`setup.py` 를 쓰셨다면 마지막에 출력된 값을 그대로 복사해서 붙여넣으면 됩니다.

### 5단계 — 첫 실행

저장소 → **Actions** 탭 → 왼쪽에서 `공고 알림` 선택 → **Run workflow** 클릭.

첫 실행은 **지금 올라와 있는 공고를 알림 없이 기록만** 하고,
`✅ 공고 알림 봇을 시작했습니다` 메시지 하나만 보냅니다.
이 메시지가 오면 설정이 다 된 것입니다. 이후로는 새 공고만 알려줍니다.

---

## 조건 바꾸기 / 가족 추가

`PEOPLE` Secret 값만 고치면 다음 실행부터 바로 반영됩니다.
사람을 추가하려면 뒤에 `, 이름:성별:나이` 를 이어 붙이세요.

## 내 PC에서 시험 삼아 돌려보기

```bash
python watch.py
```

토큰이 없으면 **연습 모드**로 동작해서, 보낼 내용을 텔레그램 대신 화면에만 출력합니다.

## 알아두면 좋은 점

- **주기**: 10분마다 확인합니다. GitHub 공용 스케줄러가 붐빌 때는 몇 분 늦게
  실행될 수 있어서, 실제로는 새 공고 후 **10~20분 안에** 알림이 온다고 보시면 됩니다.
- **조건을 못 읽은 공고는 일단 보냅니다.** 놓치는 것보다 낫기 때문입니다.
  알림에 `나이: 확인필요` 로 표시되니 링크를 눌러 직접 확인하세요.
- **아이 대상 공고 안전망**: 제목이나 본문에 `유아`, `어린이`, `소아` 같은 말이 있고
  등록된 아이가 있으면, 나이 표기를 못 읽었더라도 알림을 보냅니다.
  이때는 `🧒 아이 대상 공고로 보입니다` 가 함께 표시됩니다.
- **나이 표기**: `20-60세`, `만 2~12세`, `만 20세~만 59세`, `생후 6개월~36개월`,
  `6~36개월 영유아`, `6개월~5세`(단위 혼합), `만 12세 미만`, `만 7세 이상` 을 읽습니다.
  그 밖의 표기는 `확인필요` 로 두고 알림을 보냅니다.
  `09/07~09/11`(방문일), `1~2개월 사용`(기간), `12만원~16만원`(금액) 같은 숫자 범위는
  나이로 잘못 읽지 않도록 걸러냅니다.
- **KDRI 상세 조회 실패 시**에도 알림을 보내되
  `⚠️ 상세 조건을 읽지 못해 일단 보냅니다` 를 함께 표시합니다.
- **KDRI 상단 고정 공지**(공지사항, 문의 번호 안내 등)는 본문에 연령이 적혀 있어
  자동으로 구분되지 않습니다. 다만 고정글이라 첫 실행 때 기록되므로 알림은 가지 않습니다.
- **엘리드 공지글**(필독 사항 등)은 나이·성별이 둘 다 비어 있어 자동으로 걸러집니다.
- **`seen.json`** 은 이미 확인한 글 번호입니다. Actions가 매번 갱신해 커밋합니다.
  이 파일을 지우면 다음 실행이 "첫 실행"이 되어 현재 공고를 다시 기록만 하고 넘어갑니다.
- 공개 저장소의 스케줄 워크플로는 저장소가 **60일간 아무 활동이 없으면** 자동으로
  꺼집니다. 이 봇은 `seen.json`을 계속 커밋하므로 보통 문제되지 않지만,
  알림이 끊기면 Actions 탭에서 다시 켜 주세요.

## 사이트가 개편되면

`watch.py` 실행 시 `목록 표를 찾지 못했습니다` 오류가 나면 게시판 구조가 바뀐 것입니다.
이때는 두 사이트 모두 읽기에 실패한 경우에 한해 텔레그램으로 경고 메시지를 보냅니다.
